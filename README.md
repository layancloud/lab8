# KNN
This machine learning lab utilizes the K-Nearest Neighbors (KNN) classifier for predicting the Target class.

Steps :   
- Normalizing Data: Features have been normalized by using StandardScaler method.
- Elbow Method: Error rates for different values of K between 1 and 40 have been considered.
- Choosing optimal K: The best trade-off value between error rates is chosen which in this case turns out to be K = 30.  
- Testing Performance: Model gives good results in terms of precision and recall.
